# Devaraj Khanapuri — Portfolio

A custom responsive portfolio for Devaraj Khanapuri.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub REST API

The portfolio's public skills/content are based on the supplied resume and public GitHub profile. The technologies used to build the website are not presented as Devaraj's professional skills.

## Run
Open `index.html` with VS Code Live Server or any static web server.

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Deploy
Suitable for GitHub Pages, Vercel, Netlify, or other static hosting.
